# Frontend — AI Data Doctor React Dashboard

Modern React 19 + Vite dashboard featuring client-side Papa Parse streaming and side-by-side CSV dataset comparison.

## Setup Instructions

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Configure Environment Variables**:
   Copy `.env.example` to `.env`:
   ```bash
   cp .env.example .env
   ```
   Ensure `VITE_REACT_APP_BACKEND_URL` points to your running backend (defaults to `http://localhost:5000`).

3. **Start Development Server**:
   ```bash
   npm run dev
   ```

4. **Production Build**:
   ```bash
   npm run build
   ```

For full system architecture and platform documentation, please refer to the [Root README.md](../README.md).
